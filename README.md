# projet_rust

## Explication des différents modules

Le projet est organisé en modules Rust, chacun ayant une responsabilité spécifique :

main.rs : Point d'entrée et logique principale du jeu
game.rs : Gestion de l'état global du jeu
map.rs : Gestion de la carte et des tuiles
player.rs : Définition et comportement du joueur
monster.rs : Définition et comportement des monstres
